# ADR-012: Rebrand Visual 2026 — Migración a Light Mode

**Status:** Accepted  
**Date:** 2026-06-16  
**Branch:** epic/rebrand-2026  

## Contexto

El portfolio `mi-portafolio` operaba con un dark mode basado en paleta
`obsidian/cobalt/mint/cyan-institutional` (azules eléctricos y neón) poco
diferenciado del estándar de portfolios técnicos genéricos. El objetivo de
FEATURE-06 (página /agencias) y la estrategia B2B hacia agencias de diseño
requería una identidad visual que transmitiera sensibilidad estética y
autoridad profesional simultáneamente.

## Decisión

Migrar a light mode completo con paleta ColorHunt pastel (#96B6C5, #ADC4CE,
#EEE0C9, #F1F0E8) manteniendo secciones dark intencionales (navy #2C3340)
para contraste de alto impacto. Eliminar toda referencia a cyan neón, cobalt
eléctrico y mint brillante.

## Paleta adoptada

| Token | HEX | Uso |
|-------|-----|-----|
| navy | #2C3340 | Fondos dark intencionales, textos sobre claro, botones CTA |
| navy-deep | #1a1f28 | Gradientes oscuros |
| steel-blue | #96B6C5 | Acentos, bordes, viñetas decorativas |
| mist-blue | #ADC4CE | Acentos claros, badges, bordes suaves |
| sand | #EEE0C9 | Fondos cálidos de sección |
| cream | #F1F0E8 | Fondo general, textos sobre dark |
| slate | #4B5563 | Texto secundario sobre fondos claros |

## Arquitectura de secciones (patrón alternado)

Hero → dark navy | Para quién → sand | Colaboración → cream |
Proceso → steel-blue | FAQ → sand | CTA → dark navy

## Trade-offs

**A favor:** Diferenciación visual ante audiencia de diseñadores, contraste
claro/oscuro dinámico, paleta con 25k likes validada en comunidad de diseño,
100% WCAG AA en combinaciones finales.

**En contra:** Migración costosa (17+ archivos), algunas secciones (Works,
ProjectDetail) mantienen dark mode por complejidad de migración — registradas
como deuda técnica DT-08-01 y DT-08-02.

## Alternativas descartadas

- Mantener dark mode con cambio de acentos solamente → descartado, insuficiente
  diferenciación visual para audiencia B2B de agencias
- Light mode completo incluyendo Works/ProjectDetail → descartado en esta epic
  por complejidad y riesgo de regresiones

## Deuda técnica generada

- DT-08-01: Works.jsx — bg-obsidian, ProjectCard dark mode, pendiente migración
- DT-08-02: ProjectDetail.jsx — página completa bg-obsidian, pendiente migración
- DT-08-03: Issues MEDIO del audit de contraste — pendiente próxima iteración
