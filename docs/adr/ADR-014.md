---

## Context

FEATURE-10 includes an initial Portuguese translation for UI locale files,
project data, and blog data. Unlike the original ES/EN i18n work, the PT draft
is generated during implementation by AI and has not been reviewed by a human
Portuguese speaker or by Leo.

Portuguese content has user-facing business impact: service descriptions,
project positioning, blog posts, CTA copy, and form labels all shape credibility
with lusophone visitors. AI translation can introduce subtle issues such as
false friends, unnatural idioms, regional mismatches between Brazilian and
European Portuguese, or tone drift from the existing brand voice.

The engineering deliverable can include a complete draft, but that draft must
not be treated as final publish-ready content.

---

## Decision

Every new Portuguese content file generated by AI must include this exact header
comment until Leo reviews and approves the translation:

```js
// TODO(leo): revisar traducción PT — generado por IA, no validado
```

This applies to:

- `src/locales/pt/*.js`
- `src/data/projects.pt.js`
- `src/features/blog/data/blogData.pt.js`

The marker is a merge gate for promotion to `main`. It may only be removed by
Leo or after Leo gives explicit approval. Engineering tasks must preserve the
marker during implementation, tests, formatting, and follow-up changes.

---

## Consequences

**Positive**:
- Review status is visible directly in the files that carry the risk
- The feature can progress technically without pretending the content is final
- PR reviewers can enforce the gate with a simple grep for `TODO(leo)`
- Future edits inherit the same policy until the marker is intentionally removed

**Negative / Trade-offs**:
- The codebase temporarily contains intentional TODO comments
- A merge to `main` requires an explicit content review step outside automated
  tests
- The marker must be preserved across mechanical edits and refactors

**Neutral**:
- The marker does not change runtime behavior
- The PT locale can still be tested end to end while content review is pending
- The policy applies only to AI-generated Portuguese content for this feature

---

## Alternatives Rejected

**Track review status only in the PR description**: Rejected. PR descriptions
are easier to miss and do not travel with the files after merge or cherry-pick.

**Use a runtime `_reviewed: false` field in every data object**: Rejected as the
primary mechanism because UI locale files are plain objects with existing
contracts. Adding runtime fields would leak editorial workflow into production
data shape.

**Ship without a marker and rely on memory**: Rejected. Translation review is a
known risk and must be mechanically visible.
