# ADR-001 — Vite como build tool

**Fecha:** 10 de Abril de 2026
**Estado:** Aceptado

## Contexto
Portfolio SPA sin necesidad de SSR ni SSG. Se requería un build tool rápido, con HMR eficiente en desarrollo y optimizaciones automáticas de chunks para producción.

## Alternativas consideradas
| Alternativa | Pro | Contra |
|-------------|-----|--------|
| Create React App | Estándar, sin configuración | Deprecado, bundle lento, HMR lento |
| Next.js | Full-stack, SSR/SSG | Overhead innecesario para SPA, mayor complejidad |
| Webpack | Flexible, maduro | Configuración compleja, HMR lento |

## Decisión
**Vite v6.3.5** por:
- HMR instantáneo en desarrollo (< 100ms)
- Build optimizado con chunks automáticos (vendor, ui)
- Soporte nativo de `vite-imagetools` para optimización de imágenes
- esbuild para minificación rápida (target: esnext)
- `@vitejs/plugin-react` v4.4.1 para React 19 con Fast Refresh

## Consecuencias
**Positivas:**
- Tiempo de build < 1s en desarrollo
- Chunking automático: vendor.js, ui.js, main.js
- CSS code splitting habilitado
- Pre-bundling inteligente de dependencias (React, Framer Motion, React Icons)
- Soporte de path aliases (`@/`, `@components/`, etc.)

**Negativas / Deuda asumida:**
- Requirejs/CommonJS no soportado (ESM only)
- Menor compatibilidad con navegadores muy antiguos (target: esnext)

## Revisión sugerida
Si se requiere SSR o SSG, migrar a Astro o Next.js.
